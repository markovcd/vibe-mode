# Lexicon

Shared vocabulary. The point of naming these is that a named feeling can be acted
on in one second instead of argued about for thirty.

---

**the hum** — Code going down easy, each line suggesting the next. You're
transcribing, not deciding. Don't interrupt it for anything.

**the click** — Two separate things turn out to be one thing. An interface
collapses; a special case dissolves. Highest-value signal there is. Write it down
immediately and rebuild the plan around it.

**the drag** — Every line is a negotiation. You keep adding parameters. You're
working around code you wrote twenty minutes ago. The shape is wrong. Back up;
don't push through.

**the itch** — It works but you can't put it down. Something small and real is
wrong at the spot your attention keeps returning to. Go look.

**the ick** — Faint recoil at code you just wrote. A defect you haven't located
yet. The one hard stop in the whole mode. Never override it.

**the shrug** — Genuine indifference between options. Permission to move at full
speed. Take the left one.

**the pull** — Wanting to go look at something slightly off-path. Usually
something's actually there. Two minutes, then decide.

**the flatline** — Nothing comes. Means you don't have enough contact with the
real material. Not a cue to think harder — a cue to open a file.

---

**the peak** — The moment it works and you're still excited. Ship here.

**gold-plating** — Any work done past the peak. Recognizable by the fact that it
feels like diligence and reads, later, like noise.

**a costume** — Any activity that looks like rigor and functions as
procrastination. Reorganizing directories mid-feature. Reading docs front to
back. Writing tests for code you can see is correct. Building option tables
instead of choosing.

**the parking lot** — The running list where tangents go to wait. Write the line,
don't chase it.

**full-width first pass** — Writing the whole thing end to end before fixing
anything. Editing mid-draft loses the shape, and the shape is the valuable part.

**loop speed** — How long edit-run-see takes. Determines which mode you're
allowed to be in. Under ten seconds, instinct is affordable. Over sixty, you're
forced into deliberation whether you like it or not. Fix this before you fix
anything else.

**re-entry** — Getting back into flow after an interruption. Done by making one
small concrete change, never by re-reading. Cheapest if you stopped mid-line on
purpose.

**contact** — Touching the real material: running the thing, opening the file,
reading the actual error. The feeling runs on contact. No contact, no signal.

**the mouth test** — Saying a name in your head. If you stumble, the design is
unclear, not the name.

**a lie** — A name that was accurate three commits ago and isn't now. Worse than
a vague name, because it's believed.

**the thing** — What has to exist at the end. Running, touchable, imperfect,
alive. Not a document about it.
